# 主题切换卡顿与 Ramp 地面箭头修复

范围：ui-draft 独立入口；共享引擎源文件作为只读构建输入。未提交、推送或部署。主观视觉待用户验收。

## 主题切换

浏览器证据确认，原主题 API 在 View Transition 更新回调内等待 iframe 连续两次 requestAnimationFrame；页面截图阶段暂停了该 iframe 的帧回调，出现 `Transition was aborted because of timeout in DOM update`。前一轮中间构建的记录显示，更新约等待 4020ms 后超时，展开动画没有正常开始。

草稿构建移除了主题提交中的双帧等待，同步完成颜色和 WebGL 更新。展开仍由右上角主题按钮向左下覆盖，动画时长 400ms、原缓动曲线；用 clip-path 圆形裁剪替换逐帧重绘的径向渐变遮罩。快照过渡期间暂停持续行驶的渲染提交，完成后按原播放意图继续。日常状态发布不再触发地面射线审计，版本特效也不再并行启动另一套渲染时钟。

最终可见浏览器实测四次切换：总完成时间 460.7 / 422.1 / 427.3 / 423.8ms，每轮均无超时、无超过 50ms 的长任务。四个 1.1 秒观察窗口最大帧间隔分别为 34.2 / 9.3 / 17.1 / 9.3ms；首轮仍有一次 34.2ms 间隔，不能声称所有帧都满足 16.7ms。实际帧时间戳、长任务和动画开始/完成时间见 `20261021-theme-after.json`。最初 `20261021-theme-before.json` 的帧样本不足，禁止用它宣称帧率提升百分比。

主工作台也通过真实按钮完成切换，约 444.9ms 结束，过渡后 playing=true、距离继续增加。截图 `20261021-theme-wipe-mid.png` 显示展开中间状态。

## Ramp 地面箭头

此前 Exit 方向箭头属于独立版本图层，未接入连续行驶，车辆位置和箭头位置都固定，产生箭头跟车的视觉错误。修复后箭头读取与道路虚线相同的行驶距离，按 16.8m/s 经过车底；90 米一组、30 米行距，以共享几何副本补到远处，避免近处跳回。

浏览器确定性渲染采样记录 0–1 秒：ego 位置始终为 [0,0.02,0]，箭头 z 从 0 增至 16.8，补充组从 -90 增至 -73.2。曲线上的 Merge 和 Junction 标识不套用直线平移，避免滑出其道路。截图 `20261021-ramp-ground-marks.png`；位置样本也保存在最终 JSON 的 poses 中。

16 项 Node 测试通过，构建通过，diff 空白检查通过。覆盖箭头速度、循环行距、确定性恢复、曲线标识保护以及 iframe 帧回调暂停时主题提交可完成的回归。运行入口的脚本和 runtime 资源已更新版本参数，避免浏览器继续使用旧资源。
