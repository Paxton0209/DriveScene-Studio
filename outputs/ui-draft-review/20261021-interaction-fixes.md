# 草稿交互修复记录

范围为 `studio/ui-draft/`，共享场景引擎文件未修改，未提交、推送或部署。场景光照、雾和材质保留原版。

## 修复

- Ramp 的 Exit、Merge 纳入持续行驶；保留暂停与页面隐藏保护。
- Junction 删除同步移动/抬升的五秒循环，直接采样原版 `startCameraMotion`，沿用原版延迟抬镜头曲线。
- Road 参数区和 Export 去掉继承的额外 16px 内边距，与 Vehicle、Layers 对齐。
- 主题切换恢复原版太阳/月亮变形及右上角径向展开，补齐可连续插值的 `--theme-radius` 注册。按用户后续要求，图标由 22px 收到 18px，按钮点击范围不缩小。
- 参数恢复默认静音，只有显式 Assist 操作传递发声意图。场景切换停止上一段尚未播完的开启声音；恢复保存的 Assist 状态不会重新扫面。
- 场景异步截图后增加过期请求检查，过期切换不再应用参数或显示超时反馈。
- 初始化时恢复 Traffic 保存状态，修复开关关闭但刷新后仍有车流的不一致。

## 实测

`driving-regression.json`：Exit、Merge 各运行约 1.2 秒，距离从 0 增至 20.16 米，playing=true；暂停后距离保持 20.16。Junction 以 1/60 秒逻辑间隔采样原版轨迹，0–0.3 秒车辆前进且相机高度保持 8.5，随后抬镜头。该数据是确定性渲染采样，不代表屏幕实测 60fps 录像。

`interaction-regression.json`：隔离页面连续八次切场景，音效计数 0→0；调整车道、视角、天气、车流、车型和主题后仍为 0；主动开启为 0→1；重复相同状态以及关闭不重播开启声。四个检查器区域的左右边界均为 990/1230，主题图标为 18×18。

12 项 Node 测试通过，UI draft 构建通过，git diff 空白检查通过。截图为 `20261021-ramp-ui.png`。视听效果待用户验收。
