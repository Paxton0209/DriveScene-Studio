# 质感试版撤回与回归检查

用户否定本轮 Before / After 的蒙白、雾重观感。新增主光、天空、远景雾、建筑反射及绿植降饱和全部撤回；删除 scene-look 模块及运行时注入，保留原引擎渲染参数。没有把试版设为默认，也没有提交、推送或部署。本轮不再向桌面输出文件。

试版包装材质时，派生车道线材质再次调用已包装的基础材质，造成 shader uniform 重复定义并编译失败，标线因此消失。整个实验注入已移除，恢复原始材质编译链。新增测试比对草稿 world 补丁与原 world 源码，允许的差异仅为原有页面隐藏时暂停渲染及资源路径转换，防止再次带入被否决的 shader。

保留用户另外要求的界面修正：Driving assist 两种状态均使用相同文字，删除文字宽度动画；Road 参数行、Export Format 和 Size 使用同一列宽。浏览器实测三组分段控件与 Format 控件均为 x=1074、宽140、高28 CSS px；Size 的值区域同样 x=1074、宽140。开关前后方向盘 x=1055.242、宽18，文字 x=1081.242、宽83.508，均无变化，语义状态仍通过 aria-checked 更新。

验证：ui-draft 的 npm test 8项通过，npm run build 通过。内置浏览器检查浅色 Road 与深色 Ramp，车道虚线、边线及箭头恢复，当前捕获的控制台错误为0。截图为 rollback-road-light.png 与 rollback-ramp-dark.png。此检查不代表完成所有场景或性能验收。

仍待处理：用户指出深色匝道天空与地面过渡割裂，尚未另行修改，避免在撤回请求后继续改光影。用户关于右上角图标与动效的最后一句语音识别不完整，已询问是否要恢复旧太阳／月亮图标及主题切换动效，等待澄清。
