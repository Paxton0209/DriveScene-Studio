# Ramp 行驶循环：25 秒

按用户确认，完整周期为 25 秒，速度保持 16.8m/s，对应每轮 420m。出口和汇入的路面分支、分支边线及指向箭头采用同一距离相位。驶过后保留连续主路与普通车道虚线，下一轮从远处进入。没有增加界面控件，没有改变光照、雾、材质、智驾声音或主题切换参数。

此实现替代上一轮报告中的 90m 箭头补行方案。箭头不再单独重复补到车前，匝道几何也随行驶过程通过。主路底面和可调整长度的右边线补齐通过后的直路，固定左边线与普通虚线沿用原连续行驶逻辑。
