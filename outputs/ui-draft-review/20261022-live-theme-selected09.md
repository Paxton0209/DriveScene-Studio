# 实时主题切换与 09 音效接入

本记录覆盖同日早先报告中“主题切换期间暂停渲染”和“08K 为当前提示音”的状态。修改仍限定在 ui-draft，原工作台、材质草稿和 Earshot 试听库保持不变。

## 用户选定的声音

开启采用用户试听选择的 09「极简电子」，源 WAV 保持不变，时长 615ms。退出仅保留开启中的第一个音节，正向播放；在第二声起音的 230ms 前截断，并给末尾 18ms 加平滑衰减。前 212ms PCM 与原开启声逐样本相同，没有变调、倒放或加入其他声源。生成脚本和 SHA-256 位于 `studio/ui-draft/sounds/prepare-selected09.py` 与 `selected09.json`。原音来源和 MIT 许可沿用 Earshot SOURCES.md / EARSHOT-LICENSE.txt。

浏览器实测一次主动开启产生 plays=1，一次主动退出产生 exitPlays=1，分别解码为 615ms 与 230ms，failures=0。切换场景后两项计数均不增加。异步解码或恢复 AudioContext 被静音操作取消时，不会在稍后补播旧声音。`sound-ab.html` 已默认选中 09，退出按钮播放新首音节版本；08 只保留作对照，原 Earshot 页面保留其历史候选。

## 主题切换的停顿修复

旧方案会暂停物理时钟，并将整个场景包含在旧静态快照里。现在画板使用独立的 live-scene 过渡层，隐藏该层的旧快照，持续显示实时新画面。界面仍保留从右上角展开的 400ms 圆形效果；3D 材质、灯光、天空和天气颜色由原渲染循环连续插值，不另起物理循环、不创建第二套渲染器，也不同时渲染深浅两份场景。

播放中的车流和道路继续前进；原本暂停的泊车场景只更新颜色，不改变行驶距离或播放状态。路口保留原始轨迹采样器，主题变化不会重新建立或重置接近路口的时间线。天气配色与地平线曲线采用同一个连续权重，避免中间帧先切天气、再切天空造成亮色横带。深浅两端的目标色保持不变。

内置浏览器检查 Road / Ramp / Junction / Parking，各做深浅往返，共 8 次切换。初次针对性回归的 18 项断言通过，未捕获应用异常；切换可见期间每次有 23–25 次实际渲染调用，播放中的逻辑时间持续增加，暂停中的泊车逻辑时间保持不变。采样中的浏览器回调最大间隔约 9.2–9.4ms，未记录到超过 50ms 的长任务。这是本机、此次采样范围的数据，不代表其他设备或所有冷加载条件均已达标。

最终雪天实际屏幕录制在 `20261022-live-theme-recording-final/`，含 83 张屏幕 JPEG 与浏览器原始时间戳。录制不是均匀间隔采样，不能把帧数直接当成稳定帧率。已检查圆形展开中间帧、车流位移、天空连续变化及最后一帧；主观观感仍为**待用户验收**。更早的试录文件不作为最终外观证据。

测试覆盖原声 PCM 一致性、尾部零点、延迟声音取消、颜色插值端点、连续天气权重和实时过渡分层；39 项草稿测试、79 项共享测试及独立草稿构建通过。最终针对性浏览器回归保存为 `20261022-live-theme-and-selected09-final.json`，18 项断言通过；定稿试听页也实际播放并显示开启 615ms、首音节退出 230ms。此前报告中的冷切场景尖峰和 p95 性能边界仍保留，不能用这次主题局部测试替代全面性能认证。
