## 修订 v7 · 播放与 Assist 的交互模型（定稿）
两个独立维度，互不驱动：**播放只管时间，Assist 只管自车的驾驶模式。**
1. 持续行驶类场景默认播放，自车一直往前开，与 Assist 开关无关。Assist 关闭 = 人工驾驶（无路径线）；开启 = 辅助驾驶（路径线 + 开启音效）。车速、车流不因 Assist 改变。
2. 播放中打开 Assist：照现有 finish-110 逻辑播放路径展开动效和 08K 音效，车继续行驶。关闭 Assist：路径按现有 144ms 收回。
3. 暂停 = 冻结整个世界的当前帧，包括路径线。路径线保持可见，原样停住，不消失、不重播。恢复播放后从原状态继续，不重新展开、不重放音效。
4. 暂停状态下打开 Assist：路径线直接以最终形态出现，不播展开动效，不播音效；状态切换只靠复选框形变动效反馈。暂停时关闭 Assist：路径立即消失。
5. 导出 = 导出当前帧，所见即所得。若导出时路径正在展开，等展开完成后再取帧。
6. 页面加载或恢复已保存状态时不播音效（沿用现有规则）。系统开启减少动态效果时默认暂停。
7. 验收：播放中开/关、暂停中开/关、开着 Assist 暂停后再恢复，这三条路径各录一段，报告 path 可见性、revealing 状态、声音 plays 计数和行驶 distance。

## 修订 v8 · 去描边（覆盖 v2 / v6 中所有 0.5px 深色外描边）

- 凸起面（选中块、普通按钮）：浅 `0 1px 3px rgba(0,0,0,.07), 0 1px 1px rgba(0,0,0,.04), inset 0 .5px 0 #fff`；深 `0 1px 3px rgba(0,0,0,.35), 0 1px 1px rgba(0,0,0,.2), inset 0 .5px 0 rgba(255,255,255,.08)`。
- 凹槽轨道：浅 `inset 0 1px 1.5px rgba(0,0,0,.05)`；深 `inset 0 1px 2px rgba(0,0,0,.28)`。
- 复选框选中：`inset 0 .5px 0 rgba(255,255,255,.3), 0 1px 2px rgba(10,108,255,.3)`。
- 毛玻璃控件：浅 `0 4px 16px rgba(0,0,0,.10), 0 1px 3px rgba(0,0,0,.06), inset 0 .5px 0 rgba(255,255,255,.8)`；深 `0 4px 16px rgba(0,0,0,.3), 0 1px 3px rgba(0,0,0,.2), inset 0 .5px 0 rgba(255,255,255,.1)`。
- 画板：浅 `0 1px 2px rgba(0,0,0,.05), 0 8px 28px rgba(0,0,0,.07)`；深 `0 1px 2px rgba(0,0,0,.3), 0 8px 28px rgba(0,0,0,.35)`。

## 修订 v10 · 持续行驶、视频导出、停止逻辑
1. 可复现的随机：建筑、树、车流的生成改为「场景种子 + 行驶距离」决定。同一场景从同一位置开始，每次看到的序列完全一致。本次不加换种子的控件，种子固定写在场景画板对象里（呼应第 7 节的画板化）。
2. 视频导出：
   - Export 格式下拉新增「Video · MP4」。选中后左侧尺寸栏显示「1920 × 1080 · 10s」，点击可在 5s / 10s 间切换。不新增其他控件。
   - 离线逐帧渲染（固定时间步长，30fps），不是实时录屏；结果与机器性能无关，不能掉帧。
   - 从当前状态向后录制，所见即所得（Assist 路径线、图层显隐、天气、主题都与画面一致）。默认不带音轨。
   - 进度显示在 Export 按钮内：按钮底色从左向右填充，文字显示「Exporting 42%」；Esc 取消。导出期间交互画面冻结，结束后恢复。
   - 浏览器不支持 MP4（H.264）编码时，退回 WebM，并在下拉里如实标为「Video · WebM」。
3. 停止与资源：
   - 页面不可见时停止渲染，回来后原位继续（现有逻辑保留）。
   - 5 分钟无任何输入则自动暂停，角落按钮切成播放态；任何输入（含点击播放）恢复。
   - 浮动原点：行驶每满约 1km，把世界坐标整体平移回原点附近，画面无跳变；验收时连续行驶 ≥10km，远处物体无抖动、无漂移。
   - 对象池回收保持，连续行驶 30 分钟内存不持续增长（报告起止 JS heap 与对象计数）。
4. 验收追加：同一场景两次从头开始各截 3 个同距离帧，像素一致；导出 5s 视频一份放 outputs/，报告实际帧数与时长。
