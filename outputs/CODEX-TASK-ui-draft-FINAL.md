## 1. 设计规范（全局，优先级最高）
- 4pt 网格。间距只取 4 / 8 / 12 / 16 / 24 / 40；面板左右边距只能是 16。
- 高度只取 20 / 24 / 26 / 28 / 30 / 32 / 44。
- 圆角只有四档：4 嵌套元素（分段选中块、复选框、缩略图）/ 6 所有控件（按钮、分段轨道、列表行、侧栏行、图标按钮、选择框）/ 8 容器（场景画板、弹层、车型展示位）/ 16 圆形按钮。嵌套圆角 = 外圆角 − 内边距。
- 字体：Inter / 系统字体，数字等宽（tnum）。只有五级：13/600（场景名）、13/400·500（行标签、车名）、12/500（控件文字）、12/400 灰（左列字段名）、11/600 灰（分组标题，句首大写）。
- 颜色
  - 浅：面板 #FBFBFC，画布 #ECEDEF，分隔线 #E6E6E9，文字 #18181B，次要 #66666E，凹槽 #EFEFF2。
  - 深：面板 #1C1C1F，画布 #111113，分隔线 #2C2C31，文字 #F2F2F4，次要 #A1A1AA，凹槽 #26262B。
  - 强调色 #0A6CFF：只用于复选框选中、车型选中描边、键盘焦点环。选中行一律中性灰。
- 层级只有四级：E−1 凹槽 / E0 平面（1px 分隔线）/ E1 凸起 / E2 弹层。
- 材质（以 Apple 官方做法为最高标准）：**纯色 + 柔和投影**。控件不用渐变，也不用深色描边制造质感。
  - 凸起面（分段选中块、普通按钮）：浅 纯色 #FFFFFF，阴影 `0 1px 3px rgba(0,0,0,.08), 0 1px 1px rgba(0,0,0,.04)`；深 纯色 #46464D，阴影 `0 1px 3px rgba(0,0,0,.35), 0 1px 1px rgba(0,0,0,.2)`。不加顶部高光。

## 3. 动效
1. **保留**现有切换形变动效（ui-motion.js：选中层 320ms、toggle 224ms、左侧 tab / 右侧 segment / toggle 的累计形变比例，含可中断接续）。用户明确喜欢。侧栏选中、分段控件、复选框三类切换都复用这套弹性形变，参数不改，只适配新尺寸。不要换成普通淡入淡出。
2. 按压：按钮与可点行按下缩放约 0.97，干脆的弹簧；纯图标按钮（28/32）约 0.94。
3. 悬停只在 `(hover: hover) and (pointer: fine)` 下生效，触屏点后不残留。悬停背景过渡 120ms。
4. 文案或图标替换（Export 按钮场景名、播放/暂停图标）：短暂模糊交叉淡入，宽度用弹簧过渡。
5. prefers-reduced-motion：去掉缩放与形变，只留淡入淡出，并默认暂停画面。
6. 控件精致度对齐 Apple OS 27 的标准，交互可参考 https://uiarc.dev/components/button 。只取交互，不照搬视觉。

## 4. 播放与 Assist 的交互模型
两个独立维度，互不驱动：**播放只管时间，Assist 只管自车的驾驶模式。**
1. 持续行驶类场景默认播放，自车一直前进，与 Assist 无关。Assist 关 = 人工驾驶（无路径线）；开 = 辅助驾驶（路径线 + 开启音效）。车速、车流不因 Assist 改变。
2. 播放中打开 Assist：按现有 finish-110 逻辑展开路径并播放 08K 音效。关闭：按现有 144ms 收回。
3. 暂停 = 冻结整个世界当前帧，路径线原样保留；恢复后继续，不重新展开、不重放音效。
4. 暂停中打开 Assist：路径直接以最终形态出现，无展开、无音效（反馈只靠复选框动效）。暂停中关闭：路径立即消失。
5. 导出所见即所得；若路径正在展开，等展开完成再取帧或开始录制。
6. 页面加载或恢复已保存状态时不播音效（沿用现有规则）。
7. 快捷键（输入框聚焦时不响应，提示写进 title）：Space 播放/暂停 · A Assist path · T Traffic · V 换车 · 1/2/3 车道 2/4/6 · ⌘E 导出 · R 路口从头重播。

## 5. 持续行驶、视频导出、停止逻辑
1. 可复现：建筑、树、车流由「场景种子 + 行驶距离」决定，同一场景从同一位置开始，序列完全一致。本次不加换种子控件，种子存放在场景画板对象中。
2. 视频导出：
   - 离线逐帧渲染（固定步长 30fps），不是实时录屏，结果与机器性能无关。
   - 从当前状态向后录制，所见即所得，默认无音轨。
   - 进度显示在 Export 按钮内：底色从左向右填充，文字「Exporting 42%」，Esc 取消。导出期间交互画面冻结，结束恢复。
   - 不支持 MP4（H.264）时退回 WebM，下拉如实标「Video · WebM」。
3. 停止与资源：
   - 页面不可见时停止渲染，回来原位继续。
   - 5 分钟无输入自动暂停，角落键切为播放态，任何输入恢复。
   - 浮动原点：每行驶约 1km 把世界坐标平移回原点，画面无跳变。
   - 对象池回收保持，内存不随时间增长。

## 10. 细节打磨清单（2026-10-20 设计复查，优先级高于参照源；与前文冲突处以本节为准）
设计负责人逐项复查后列出。每条都要在验收报告里单独打勾，并附截图或实测值。

### 10.1 字体与渲染
1. 字体栈改为系统优先：`-apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", Inter, sans-serif`。macOS 上必须渲染为 SF Pro，Inter 只作非 Apple 平台的后备。
2. 全界面 `-webkit-font-smoothing: antialiased`。UI 外壳（工具栏、侧栏、检查器）`user-select: none`，只有可编辑字段可选中文字。
3. 所有数字（车道数、1920 × 1080、导出百分比、时长）用 `font-variant-numeric: tabular-nums`，切换时不跳宽。「×」两侧各一个窄空格（U+202F）。
4. 选中态只改背景，不改字重导致文字跳宽：选中项字重 500 时，未选中项也预留 500 字宽（可用加粗文字的隐形占位，或统一用 500）。

### 10.2 发丝线与像素对齐
5. 分隔线在 DPR ≥ 2 的屏幕上为 0.5px（一个物理像素），DPR 1 为 1px；颜色不变。现在 1px CSS 在 Retina 上是 2 个物理像素，显得粗。
6. 所有元素的坐标与尺寸落在整数 CSS 像素上（画板居中计算后 `Math.round`），避免文字和图标发虚。
7. 图标按尺寸统一描边粗细：12px → 1.6，14px → 1.4，16px → 1.5，侧栏 20px 彩色图标无描边。现在 1.3 / 1.4 / 1.6 / 1.7 混用，要统一。
8. 图标尺寸只有四档：12（下拉箭头、播放键图标）、14（分段控件内图标，如天气）、16（工具栏、眼睛）、20（侧栏）。天气图标从 13 改为 14。

### 10.3 信息重复
9. 场景名现在出现三次：工具栏、画板标签、Export 按钮。改为：
   - 工具栏左侧显示项目名「DriveScene Studio」（13/600），后面不跟副标题；
   - 画板上方标签显示场景名和参数，例如「Road · 6 lanes · Low」，左对齐（这是 Sketch 的画板名位置，也为将来多画板做准备），右侧仍是「1920 × 1080」；
   - Export 按钮只写「Export」，右侧「⌘E」。
10. 检查器行内的快捷键字母（Assist path 后的「A」）去掉，快捷键只出现在提示里。Apple 的检查器不在行内显示快捷键。

### 10.4 控件语义
11. 只读与可交互要看得出区别：Export 行里的「1920 × 1080」在图片格式下只读，去掉底色，显示为纯文字（12/400 灰）。只有选了视频格式、时长可点击时，才显示为带凹槽底的可点控件（「10s ▾」）。
12. 眼睛「隐藏」态改为 Apple 的 eye.slash 形式（同一个眼睛 + 一条左上到右下的斜线），不要用另画的闭眼形状。两种状态外轮廓要一致，切换时只淡入斜线（120ms）。
13. 鼠标指针：按钮、行、分段控件一律用默认箭头（macOS 惯例），只有真正的链接用手形。删掉所有 `cursor: pointer`。
14. 主题切换按钮的图标要反映当前状态：浅色显示月亮（点击切到深色），深色显示太阳。图标切换用模糊交叉淡入。

### 10.5 画面与播放键
15. 播放键自动隐藏：播放中，指针离开画布 2 秒后，播放键 200ms 淡出到 0；指针进入画布或任何键盘操作时 150ms 淡入。暂停中始终显示。目的是让循环画面保持干净。
16. 播放键按下缩放 0.94，播放和暂停图标用模糊交叉淡入切换，不要直接替换。
17. 切换场景时，画板内容交叉淡入 200ms，画板标签文字同步淡入，画板尺寸不跳动。沿用引擎现有的 frame-cover 机制，但视觉上只能看到淡入，不能出现闪白或纯色块。
18. 画板外的画布区域不响应拖拽或选择，避免误选。

### 10.6 节奏与对齐
19. 侧栏第一个分组标题与检查器第一个元素（车型展示位）顶部对齐在同一水平线（距工具栏底 12）。画板标签不参与此对齐：标签始终紧贴居中画板上方 6px（Sketch 画板名惯例，用户已确认）。
20. 分组标题在侧栏和检查器里用同一套规格：高 28，11/600 灰，文字基线一致；侧栏左缩进 16（8 内边距 + 8 行内缩进），与检查器 16 对齐。
21. 侧栏行高 30 与检查器行高 26 保持不同（侧栏是导航，检查器是属性），但两边行内文字都必须垂直居中到整数像素。

### 10.7 主题与过渡
22. 切换浅色或深色时，UI 外壳颜色 200ms 过渡（背景、文字、分隔线、控件），不许瞬间跳色；场景渲染沿用引擎自己的主题过渡，两者同时开始。
23. 深色主题下侧栏彩色图标亮度不变，但路面灰 #596070 在深色面板上偏暗：只在深色主题把 icAsph 渐变整体提亮约 8%（上 #7D8597 → 下 #535A6A），其他颜色不动。

### 10.8 提示与滚动
24. 提示（tooltip）不用浏览器原生 title，改为自绘：深色胶囊，11/500 白字，内边距 4/8，圆角 6，E2 投影；悬停 600ms 后出现，移到相邻控件时立即切换不再等待；格式「Assist path  A」，快捷键用 60% 不透明度。浅色和深色主题外观一致。
25. 检查器滚动条用覆盖式细滚动条（宽 6，圆角 3，半透明），只在滚动时出现，1 秒后淡出；不占布局宽度。
26. 键盘焦点环只在键盘导航时出现（`:focus-visible`），鼠标点击不出现。

### 10.9 响应式
27. 窗口宽度 < 1180：左侧栏收为 56 宽的图标栏（只显示 20px 彩色图标，选中项同样用 6% 灰底，提示显示场景名）。宽度 < 960：检查器改为从右侧滑出的浮层（E2 投影，宽 260），由工具栏右侧按钮开关。任何宽度下画板都保持完整 16:9。

- 宽度 1440、1180、960 各截一张。

### 12.9 场景画面质感提升（SR 环境，逐条在 material-draft 质感基础上做；每条可开关，便于用户逐项对比验收）
1. 抗锯齿：当前 WebGL `antialias:false`，远处车道线和建筑边缘有锯齿和闪烁。改为 WebGL2 多重采样渲染目标（4×），或后处理 SMAA；按 `min(devicePixelRatio, 2)` 渲染。
2. 车道线贴图开启各向异性过滤（取设备最大值）和 mipmap，消除远处虚线闪烁；虚线两端做 0.05m 圆角。
3. 色调映射：评估 Khronos PBR Neutral（或 AgX）替代当前映射，让白车和浅灰建筑的高光不发灰、不过曝；标定曝光，使路面中部亮度与现状一致。
4. 环境光遮蔽：低强度 GTAO / SSAO（半径约 0.5m，强度 0.3–0.4），只作用于建筑底部、路缘、车底与地面交界，增加落地感。
5. 太阳阴影：软阴影（PCSS 或 VSM，半影随距离变宽），校正 bias，消除阴影悬浮和条纹。
6. 空气透视：雾颜色与天空地平线颜色一致，远处建筑逐渐降饱和、提亮；加很淡的高度雾（贴地更浓），增加纵深层次。
7. 天空：保持低反差竖向渐变，地平线处稍亮（约 +4% 亮度），不加太阳光盘。
8. 建筑：不加纹理和条纹（用户否决过）。每栋建筑基色在 ±3% 亮度内随机微差；竖直方向底部比顶部暗约 6%（接触变暗）；边缘保留现有倒角高光。
9. 路面：加极细的沥青微法线噪声（强度很低，近处可感、远处消失），避免塑料感；车道中央极淡的轮迹暗带（≤3% 亮度差）。
10. 自车：车漆使用中性棚拍 HDRI 环境反射（只影响反射，不改场景光照）；车轮随车速转动；尾灯保持现状。
11. 他车：材质与自车同一套车漆和玻璃参数，距离远时使用 LOD，保证帧率。
12. 树：降低饱和度约 10%，与建筑灰调统一；加极轻的风摆（±0.6°，周期 4–6s，各树相位随机）。
13. 性能约束：以上全部开启后，1440 宽桌面保持 60fps（帧时间 p95 ≤ 16.7ms），否则逐项回退并在报告里写明。

### 12.10 智驾线开启动效细节（外观保持 finish-110，只精修动效，全部可开关对比）
1. 起点：线从车头前保险杠下方生出，前 60ms 起点处不透明度从 0 升到 1，避免硬切出现。
2. 前沿：推进的前沿做 0.6m 的柔边羽化，不是硬切；前沿比线身亮约 15%，到达终点后 200ms 衰减回线身亮度。
3. 宽度：展开过程中宽度从 88% 弹到 100%（只在展开这 450ms 内），给一点「被拉开」的张力。
4. 节奏：按世界距离推进，ease-out（cubic-bezier(.2,.8,.2,1)），总时长 450ms，与 08K 音效同一音频时钟起止（用 AudioContext.currentTime 对齐首帧，误差 ≤ 1 帧）。
5. 落定：到位后沿线做一次很淡的光波扫过（600ms，亮度 +8%，从近到远），然后静止。用户否决过多层扫面，所以这条默认关闭，单独开关供用户对比。
6. 关闭：整体 150ms 淡出，不回缩。
7. 只对智驾线做选择性泛光（bloom 阈值只命中智驾线材质，强度很低），其他物体不发光。
8. 验收：每条附开启过程 0 / 40 / 90 / 180 / 450 / 650ms 的逐帧截图，浅色和深色各一组。
