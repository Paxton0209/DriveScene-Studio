Offline asset preparation. Install with `npm install --prefix studio/scripts/traffic-tools`, then run `node studio/scripts/traffic-tools/prepare-modern.mjs SOURCE_DIRECTORY`. The input directory contains modern-sedan-a7.glb (KiW) and modern-suv.glb (razor24). Source links and CC BY 4.0 attribution are in ../../engine/assets/traffic-README.md. The script dequantizes GLB accessors before conversion, preserves normal-aware boundaries, closes the front fascia and adds an independent opaque sealed core. Runtime has no preparation dependencies.
