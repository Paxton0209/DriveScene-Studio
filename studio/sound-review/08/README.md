# 08 开启音优化与品牌录音对照

入口：`/studio/sound-review/08/`。原08保留不动；08A为600ms柔和收束，08B为520ms清晰确认，08C为460ms克制短音。三版沿用245、367.5、612.5、980Hz骨架，失谐幅度分别为原版55%、32%、18%，分别在280、220、180ms内稳定。气流与混响逐级减少，C不使用气流或混响。主包络在约320ms完成展开，350–380ms开始释放，配合400ms智驾线结束。

三版与原08的前400ms RMS电平对齐；这项数值对齐不等同于听感响度完全相同。音频为48kHz双声道16位PCM，边界静音，无削波。运行 `python3 studio/scripts/make-08-refinements.py`（需NumPy）可重建原创候选。下载ZIP仅含原08、三版优化及清单，不包含品牌录音。

试听使用Web Audio预解码、预定播放时间及音频输出时间戳，在对应的浏览器绘制帧启动400ms智驾线。页面记录调度事件和输出时间差，快速切换会停止旧声源并取消旧动画调度。原引擎以 `review=sound-options` 运行，抑制工作台原启用音，避免叠播。浏览器采样记录中工作台原声播放次数为0；桌面浏览器的帧同步检查不能保证所有设备或蓝牙链路都没有额外延迟。

## 品牌录音及证据边界

品牌片段首尾各用5ms淡入淡出避免裁切点击声。品牌条目保留原始速度，仅作音色、语音和节奏参考，不驱动本项目400ms动画。录音包含环境声和部分讲解；这些不是完整车厂音效库，也不代表各品牌当前所有车型版本。没有用程序合成冒充品牌原声。没有替换、修改或连接工作台正式音效。

## 本轮修订：08D–F与参考录音更正

用户反馈A–C过于平直，因此新增D「轻双音」540ms（245→275Hz，两段重叠衔接）、E「上扬收束」600ms（连续升高后小幅回落，泛音明暗同步变化）、F「明亮应答」520ms（主体轻扬，235ms加入735Hz泛音应答）。保留08的1:1.5:2.5:4和声骨架，前400ms RMS保持与原08一致。D–F使用既有音频输出时钟同步，不改变400ms智驾线及工作台音效。原版和A–C保留，A–C在页面折叠显示。

参考录音更正：小鹏片段为含语音的工程版录音，蔚来为语音确认，理想含现场讲解；不能作为清晰的非语音开启音效对照。三者已从试听界面撤下，来源信息保存在recording-sources.json，仅保留上述历史调查记录，不能据此声称取得这三品牌的独立原厂开启音。当前仅显示特斯拉社区标注片段，仍保留车型及版本未核验的说明。

## 清亮双音：08G

按用户反馈去掉低沉和下行，新增08G「清亮双音」440ms。两个固定基频349.228→391.995Hz，上行全音；第一声0–155ms，25ms静音间隔后第二声180–420ms，400ms附近释放，末20ms静音。仅含整数倍弱泛音，不含失谐、滑音、低频铺底、空间回声或混响；仍为原创程序样音。前400ms RMS继续与原08对齐，不能据此保证主观响度完全一致。

试听页首屏提供08G、上一版08D和原08，其他历史版本折叠保留。下载ZIP包含原08及A–G。播放继续沿用音频输出时钟与400ms智驾线同步，未改工作台正式音效或智驾动效参数。

## 08H：研究参考结构后拉开差异

对页面现有特斯拉社区片段逐50ms观察频谱与RMS：稳定主频约329.6→369.9Hz，上行全音；起音间隔约250ms，第二声峰值较高、衰减较长，主频占主导。结果仅对应这段录音，不能推断原厂合成方法、当前车型版本或所有开启音。官方车主手册仅确认开启提示音与蓝色方向盘/车道状态共同反馈：https://www.tesla.com/ownersmanual/model3/en_be/GUID-20F2262F-CDF6-408E-A752-2AD9B0CC2FD6.html 。

08G只换了音区，仍沿用上行全音，且早期二次泛音偏多，用户反馈不合适。新增08H「轻触确认」：440→523.251Hz上行小三度，第一声0–120ms，第二声145–415ms，前轻后长；削弱二次泛音，少量快速衰减敲击成分仅用于起音。无录音采样、低频铺底、滑音、失谐或混响。前400ms RMS与原08对齐；清晰、轻巧和差异感仍需用户试听判断，参数差异不能保证听感或品牌辨识度。首屏改为H、G、原08，A–F保留在历史折叠区，ZIP含原08及A–H。工作台原音及400ms动画不变。

## 08I：单次轻弹

用户明确音节数量可放开，新增08I「轻弹微光」430ms：一次12ms柔和起音，固定523.251Hz主音，弱泛音在前约90ms内透亮后消退，少量短促共振增加触感；整体振幅单次起势后连续衰减，275–405ms释放，余25ms静音。不另起第二声，无下行滑音、低频铺底、失谐、混响或独立高频应答。前400ms RMS仍与原08对齐，灵动和自然程度由用户试听判断。页面首屏为I、H双音对照与原08，A–G折叠保留，ZIP含原08及A–I；音频调度、400ms智驾线与工作台正式音效均不改变。

## 特斯拉双音合并实验

用户要求尝试将当前特斯拉片段的两个音合并。新增T合「特斯拉双音合并 · 实验」：直接从现有tesla-community.wav取60–315ms、320–720ms，两段起音对齐同时叠加，原音高、采样速度和音色保留；段边界做5ms淡入及35ms淡出，整体365–405ms收尾，总长430ms，前400ms RMS与原08一致。未做重新合成、变调或拉伸；较短的第一声保留原衰减后先结束，两声并非被变为一个新的单频音。

页面明确标记为参考录音编辑实验，沿用来源及版本未核验的边界，不能称为本项目原创音效或已选定方案。T合、08I与原08首屏对照，A–H折叠，原始特斯拉双音仍在参考区。合并版配合400ms智驾线；原参考单独按原节奏播放。原创WAV下载包继续仅含原08及A–I，不含该来源录音衍生实验。工作台原音不变。

## 08J：0.6秒干净单音与公开原则复核

来源为Apple WWDC17《Designing Sound》https://developer.apple.com/videos/play/wwdc2017/803/ ：根据反馈意义选择声音、控制复杂度与反复听的侵扰、去掉多余噪声/频率、精确同步动作、在目标设备试听。属于公开设计方法，未获得Apple审核或认证。

08J「清透落位」为原创程序样音，固定554.365Hz单主音，无特斯拉采样；仅保留极弱、快速衰减的二次泛音，无双主音叠加、失谐、混响、持续调制或气流噪声。文件与试听动画均600ms；旧候选仍用各自400ms动画。新增的时长覆盖只存在于sound-options试听运行时，不存储设置；工作台仍400ms及原音。

复核结果：波形边界、单次起音、无削波、600ms文件与动画设置已检查；数值见下。设计复核保留两项待验：声音主要能量在前段，后段较轻，是否足以伴随完整600ms展开要实际试听；当前音色仍较纯，不能仅靠频谱认定自然、灵动或耐听，也未完成反复使用、耳机/扬声器及车内背景噪声验证。声音只承担状态确认，仍依靠可见智驾线明确状态。整体仍是待听评候选，不能称为完成完整听感验收。

## 08K：音调降低与软化起音

用户反馈J略刺耳，新增K：554.365→440Hz固定单主音，向特斯拉参考约330–370Hz的音区靠近但不照搬；起音9→16ms、快速衰减二次泛音.025→.012，前400ms RMS比J降低约1dB。长度、连续衰减和试听智驾线仍600ms。首屏K/J/原08，T合移入历史，工作台正式音效不变。

## 当前确认版本：08K 450ms

用户认可K音色后要求缩到450ms，随后明确要求接入工作台Path。K及配套试听动画均为450ms；旧J及其他历史样音保持原版供溯源。当前正式Path资源与K样音逐字节一致，48kHz双声道PCM，峰值-11.75dBFS，无削波、首尾静音；工作台默认flow展开450ms。此前“工作台未替换”均为历史状态，已被此次明确授权与接入覆盖。
