# 智驾开启声音十案

从仓库的 `studio/` 启动本地服务器后，打开 `/sound-review/`。每个方案可单独试听，并配合当前400ms智驾开启预览；点击正在播放的方案停止。试听不会保存或替换工作台音效。`sound-options.zip`包含十个48kHz立体声16位WAV及编号清单，方便换电脑或导入音频软件比较。

## 方案

| 编号 | 方向 | 声音结构 | 总长 |
| --- | --- | --- | --- |
| 01 | 相位展开 | 气流展开、柔和谐波、窄到宽的空间变化 | 0.78s |
| 02 | 磁场上电 | 感应线圈、圆润低频、稳定的电磁调制 | 0.82s |
| 03 | 航电唤醒 | 微小继电器、短伺服、稳定电气层 | 0.72s |
| 04 | 维度开启 | 内吸气流、多层空间打开、柔和残响 | 0.96s |
| 05 | 神经接入 | 连续微颗粒、连接密度增加、汇聚成形 | 0.76s |
| 06 | 冷光扫描 | 滤波气流、纤薄扫动、轻量共鸣 | 0.68s |
| 07 | 离子推进 | 低频启动、压缩气流、短推进感 | 0.88s |
| 08 | 晶体聚合 | 失谐逐渐对齐、非旋律共鸣、清透余韵 | 0.90s |
| 09 | 引力解锁 | 下沉低频与上行空气的反向运动 | 0.94s |
| 10 | 静默智能 | 短触感脉冲、轻泛音、较少空间尾声 | 0.62s |

主体变化集中在开启的前400ms，后段用于自然衰减。当前是用于选择方向的原创程序合成样音，没有采样、复制或宣称复刻电影原声；未宣称已经过车内声学或告警区分验证。所有波形使用相同核心RMS目标和峰值上限，便于比较，听感响度仍会受到频谱和设备影响。主界面现有声音未被替换，等待用户选定编号。

## 制作参考与取舍

[Google Design：Sound & Touch](https://design.google/library/ux-sound-haptic-material-design)讨论交互声音的信息价值、自然感和使用频率。本轮保留明确的启用反馈，减少尖锐通知式旋律，不给普通tab或toggle新增声音。

[Ben Burtt谈WALL-E声音的访谈整理](https://designingsound.org/2009/09/ben-burtt-special-wall-e-the-definitive-interview/)区分实体机械的运动细节与EVE的磁场、轻盈合成音。这里借鉴机械层、空气层与电子层之间的不同组织方式，不使用作品声音素材。

[Event[0]声音团队访谈](https://www.asoundeffect.com/event0-sound/)强调飞船系统的可信技术性格及声音与动作的同步。本轮将启动、展开和稳定组织为连续事件，避免把不相关的提示音硬拼成一段。

[Keepforest：Futuristic Interface](https://keepforest.com/store/sound-effects/futuristic-interface-225461)展示以扫描、界面、动作等功能组织科幻声音库的方式。这里用不同的合成结构区分十案，未下载或使用该商业音效库。

可用Python 3与NumPy运行 `python3 scripts/make-sound-options.py`重建音频。生成器同时验证有限数值、无数字削波和首尾静音，并在 `tracks.json`记录时长、峰值、RMS和频谱重心；这些数值检查不替代听感选择。
